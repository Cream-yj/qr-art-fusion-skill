# 局部修复与受保护的合成

## 异常补块可能承担编码作用

看到灰点、白斑或黑块时，先检查它是否位于原码所需的深浅区域。直接擦除可能让原本能解码的文件失败；只把补块磨糊也可能留下不自然的脏边。

| 需要保留的作用 | 可与画面结合的修改 |
|---|---|
| 人物附近的暗部 | 有细发丝和渐细边缘的棕色卷发 |
| 花卉或衣饰附近的亮部 | 单颗光滑珍珠、清晰花瓣或自然布料亮面 |
| 蝴蝶旁的深色结构 | 与已有酒红玫瑰相连的花瓣 |
| 缎带下方的暗部 | 连贯的深色丝绸背面或衣褶 |

这些是历史修整思路，不要求每张画面使用同样物件。修后看清晰边缘、光照、遮挡和材质是否连贯，再检测完整文件；需要的明暗不是用一张阈值图宣布已经满足。

## 生成局部细节，限制合入范围

1. 保存不可变的原图和无损母版，明确本次要改的区域及保护区域。已有图层与提示词时先查源。
2. 必要时裁取带足够上下文的局部，交给可用图像编辑工具处理。提示词说明只改指定瑕疵、维持附近物件位置、原画风及所需亮暗。
3. 检查生成结果是否改变了脸、手、物件位置或光照。即便生成工具改了整图，也只合入认可的局部，不能直接以整张新生成图替换定稿。
4. 蒙版边缘适当过渡，避免残留原补块和重复高光。检查实际差异范围；只有做过对应像素检查，才宣称保护区域逐像素不变。
5. 保存合成版本，检测这份完整图；每次只根据新变化、失败或明确未解决的问题继续调整。

图像编辑与合成使用当前环境合适的工具。历史中有 Native CoreImage 局部合成实现，但本流程不要求特定操作系统或历史脚本路径。

## 将认可细节转移到另一张同源图

不要只凭两张图看起来相同就直接贴坐标。确认素材是否同源，匹配内部图像的比例、偏移和裁切；有外边框时区分整张画布与内部图像。

可通过已知图层变换或特征匹配建立对应关系，检查代表位置的误差，再转移局部修整。原图已有细微色彩差异时，可以在匹配坐标中转移认可的修改差异，保留目标图的其他像素。变换、蒙版及影响范围应作为工作记录保留。

如果来源不同或无法可靠对齐，改做受限的局部重绘并说明范围，不称为精确转移。

## 海报合成

- 独立保存背景、标题、二维码和底部说明；需要白色码区边缘时单独处理。
- 已确认的二维码与标题直接从源文件合成，不通过生成模型再次描绘。
- 检查可见边界与码区的中心，避免透明留白造成假居中。
- 保持等比例缩放。移动、缩放、裁切、换背景或导出 JPG 后，检测实际交付文件。
- 确定性像素保护的声明针对相应无损文件；有损 JPG 会重新压缩图像，不能沿用 PNG 的逐像素相等结论。

受保护的合成解决的是修改范围；二维码可读性仍由实际解码验证。
